# Planifica Maestro

Aplicación real de planificación docente con IA. Genera planificaciones diarias,
mensuales y anuales a partir de **texto**, **dictado por voz** o **foto de un libro/guía**,
para niveles Inicial, Básico (EGB), Medio (Bachillerato) y Universitario.
Exporta el resultado final a un documento **Word (.docx)** listo para imprimir.

## Puesta en marcha

### 1. Backend
```bash
cd server
npm install
cp .env.example .env
npm start   # http://localhost:3001
```

### 2. Frontend
```bash
cd client
npm install
npm run dev  # http://localhost:5173
```
